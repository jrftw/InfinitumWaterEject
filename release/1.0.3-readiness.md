# 1.0.3 (1) release preparation

Prepared November 15, 2026 on `codex/1-0-3-polish`. This candidate has not been uploaded or submitted. The existing 1.0.2 submission, listing and website were not changed by this work.

## Validation

- iPhone 18 Pro Max simulator: 23 tests, zero failures on the final candidate source.
- iPad Pro 13-inch (M5) simulator: 23 tests, zero failures. This full run preceded the final missing-custom-value fallback adjustment and restored Activity banner placement; those final changes are included in the passing iPhone run and signed archive.
- Coverage includes audio scheduling and duration, interruptions/stop behavior, free Siri/Shortcuts actions, ad placement caps, lifetime purchase/refund and legacy subscription expiry. Eight polish regressions cover history deletion and preference retention, read-only settings access, derived end timestamps, rolling date filters, reminder deduplication, persisted themes and publisher forwarding, CSV formatting, invalid preset values and zero-position/custom-default tones.
- Native screen captures reviewed on iPhone and iPad, including light appearance, dark release history and accessibility text sizes. Large-text home controls use a vertical cycle-settings layout and omit the decorative introduction.
- App Store distribution IPA export succeeded locally (`destination=export`); no upload was performed.
- Signed Release archive succeeded. App and widget are both 1.0.3 (1), deployment target iOS 16.0. `codesign --verify --deep --strict` passed on the archive.
- Tests run with the existing Debug-only snapshot argument to suppress external ad-consent forms. Normal Debug launches and Release builds retain the real consent flow. This avoids a consent modal blocking the test of the foreground Siri action; the production guard remains intact.
- `git diff --check` passed. Simulator runtime messages about audio activation/telephony were present; no project compiler warnings were reported in the successful Release archive.
